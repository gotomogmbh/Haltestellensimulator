# Haltestellen Simulator

Simulator für die Visualisierung und Kategorisierung von ZVV-Haltestellen.

## Projekt

Teil des Projekts "Haltestellen Kategorisierung" für den ZVV.

## Setup

```bash
git clone https://github.com/gotomogmbh/Haltestellensimulator
cd Haltestellensimulator
```
